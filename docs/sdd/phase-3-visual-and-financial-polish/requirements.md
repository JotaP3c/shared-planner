# Refinamento visual e financeiro

| ID | Critério |
| --- | --- |
| VIS-01 | Comparar calendário, formulários e detalhes, financeiro, catálogo, membros, usuários, perfis, pendências, login e configurações com as referências do projeto. |
| VIS-02 | Dar acesso a filtros, agenda diária e criação de eventos em telas estreitas. Adaptar navegação, controles e painéis ao espaço disponível. |
| VIS-03 | Mostrar resumo do atendimento CLIENT com itens, quantidade, duração, horário e total. Manter o autocomplete e as observações opcionais. |
| VIS-04 | Exibir os indicadores e os três gráficos financeiros em larguras diferentes. Permitir recolher os filtros do catálogo preservando o formulário. |
| FIN-01 | Exportar quantidades, valores e descontos contratados com vínculo ao atendimento. Usar os mesmos calendários, período, permissões e totais da API financeira. |
| FIN-02 | Preservar as quatro abas existentes, três gráficos nativos e compatibilidade com atendimentos legados. |
| QA-01 | Validar Java, Angular, build, PostgreSQL isolado e Chrome com temas Claro, Escuro e Sistema. |

As referências de `docs/reffs` orientam composição, densidade e hierarquia. Os
prints da auditoria registram problemas e fluxos reais. A Fase 3.0 fornece a base
financeira e a Fase 3.1 define as condições comerciais contratadas.
